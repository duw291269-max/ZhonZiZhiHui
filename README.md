

# 种子智慧个人管理 Web App (SeedLab) 需求文档

## 1. 产品定位

一款基于格西麦克·罗区“种子智慧”理论的个人修行与目标达成工具。通过数字化手段将抽象的“潜意识种子”可视化，帮助用户通过**“给予”**实现**“获得”**，并培养每日咖啡冥想的习惯。

---

## 2. 核心价值主张

* **可视化生长：** 将隐形的意识种子具象化为动态生长的 CSS 抽象植物。
* **生态维护：** 引入能量损耗机制，模拟真实的意识维护过程。
* **离线私密：** 单 HTML 文件结构，数据完全本地化，保障极端隐私。

---

## 3. 功能模块详细说明

### 3.1 目标管理（Step 1: 愿望池）

* **多目标并行：** 支持创建多个独立的目标（如：财富、关系、健康、智慧）。
* **目标设定：** 每个目标需包含：
* 目标描述（清晰、具体、可衡量的句子）。
* 所属分类（对应不同的植物外观颜色）。
* 初始种子（创建后在花园显示为一个小圆点）。



### 3.2 播种记录（Step 2 & 3: 善行日志）

* **关联伙伴：** 每次记录必须关联一个具体的“业力伙伴”姓名。
* **行为记录：** 记录为伙伴做了什么具体的帮助。
* **成长反馈：** 每次记录成功，对应目标的“高度值 (Growth)”增加。

### 3.3 咖啡冥想室（Step 4: 核心动力源）

* **全屏沉浸模式：** 点击“开始冥想”后，UI 进入暗色调，隐藏所有无关干扰。
* **呼吸计时器：** 中心圆环随呼吸频率收缩扩张（默认 5 分钟）。
* **动态引导词：**
* 屏幕轮播当日记录的善行文字。
* 随机展示内置的“格西智慧金句”。


* **能量补给：** 冥想完成后，种子的“能量值 (Vitality)”回升，植物恢复光泽。

### 3.4 虚拟花园（可视化系统）

* **抽象植物逻辑：**
* **生长阶段：** 种子 -> 破土 -> 抽叶 -> 开花（由 `Growth` 值驱动）。
* **健康状态：** 鲜艳发光（高能量） vs 灰暗干瘪（低能量）（由 `Vitality` 值驱动）。


* **天气系统：**
* **暖阳模式：** 连续冥想打卡  天，背景呈现金色暖光渐变。
* **阴天模式：** 超过 24 小时未冥想，背景逐渐变为冷灰色。



### 3.5 除草系统（四力法纠偏）

* **负面记录：** 用户记录自己的负面言行（种下坏种子）。
* **视觉惩罚：** 植物根部出现黑色刺状物（杂草），并持续降低植物能量值。
* **清理逻辑：** 用户必须点击杂草，完成“四力法”步骤（回顾动机、忏悔、承诺、补偿行动）后，杂草消失。

---

## 4. 业务逻辑与规则

### 4.1 离线生态逻辑

* **时间流逝算法：** 每次打开 App 时，计算当前时间与 `last_open_time` 的差值。
* **自然损耗：** 每 24 小时未进行咖啡冥想，植物 `Vitality` 下降 10%；超过 3 天未记录善行，背景天气变阴。
* **枯萎机制：** `Vitality` 降至 0 时，植物呈灰色枯萎态，停止生长，直到进行一次长效冥想才能唤醒。

### 4.2 数据存储规则

* **本地持久化：** 自动实时保存所有数据至浏览器 `localStorage`。
* **手动备份：** 提供“导出种子数据 (JSON)”功能，支持用户手动物理备份。

---

## 5. 交互需求

* **极简首页：** 顶部为天气状态，中部为动态花园，底部为“播种”和“冥想”两个核心按钮。
* **单手操作：** 适配移动端浏览器，所有按钮位于底部易触达区域。
* **动态动效：** 植物需有轻微的呼吸感动画（微幅缩放或歪斜）。

---

## 6. 非功能需求

* **纯单文件：** 所有的 CSS、JS 和图标（SVG）必须内嵌在 HTML 文件中，不依赖任何外部图片链接。
* **无网络访问：** 确保在完全断网的情况下，所有功能（包括计时器和植物生长逻辑）均能正常使用。
